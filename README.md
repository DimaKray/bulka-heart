# 💗 Серце з частинок

Інтерактивна WebGL-сцена на чистому HTML/JS (без залежностей і збірки).

**Три сцени:** серце з частинок → напис → об'ємне фото. Перехід між ними за кліком/дотиком.

## Ефекти
- Живий фон: туманність, мерехтливі зорі, паралакс від курсора
- Іскри за курсором
- Окремий ефект для кожного переходу: спіраль, контур-серце, кільце-хвиля
- Фото з реальним об'ємом (передня й задня поверхні + заповнення всередині), без подвоєння

## Запуск
Просто відкрий `index.html` у браузері.

## Деплой на Vercel
```
npx vercel --prod
```
Фреймворк: **Other**, збірка не потрібна. Або імпортуй репозиторій на vercel.com.

## Керування
- Клік / дотик: перехід до наступної сцени
- Перетягування: обертання моделі
- Рух миші: паралакс і слід з іскор
